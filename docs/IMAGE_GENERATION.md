# PySlate 0.2.0 教学图与生成记录

> 源码快照说明：安装包、测试报告、截图、PNG 原稿、交付校验清单及完整历史归档属于原始交付资料，未随本仓库提供。相关路径仅用于标识历史文件；本文保留的测试结果是原交付记录，不表示本次发布重新执行。当前可编辑源码位于仓库根目录。

58个主题均包含初级、中级、高级，共174个独立学习单元；每个单元使用一张专属的本地生成图。当前课程的 `tiers[].diagram` 是资源对应关系的唯一依据，原0.1版SVG保留为历史源资源，不再作为174单元的主图。

## 教学设计

所有174张主图均实际调用内置 image_gen 生成，采用暖白底、墨绿/蓝/赭黄/珊瑚色的统一立体纸艺或哑光材质风格。图像通过空间关系、对象引用、分支、前后快照、窗口或数据汇合解释概念，不以讲义段落、代码截图或大段文字充当配图。必要的数据值、索引和短标签用于明确可验证的关系。每一档围绕该档实际课程代码与问题编写图稿，不复用一张装饰图充数。

例如，二分搜索图展示目标73如何始终留在缩小的区间内；词频图展示不同大小写与首尾标点如何归并；原子导入图展示候选状态失败后正式数据保持不变；恢复图区分迁移时保存有效原文与主文件损坏时保护有效备份。图片旁的课程问题引导学生从图中推断答案，文字解释另在正文中。

## 资源与可追溯性

- `docs/IMAGE_GENERATION_V2.json`：最终选用图的实际生成提示词、原始工具输出路径与单元对应关系。
- `../artwork/masters/`：最终选用的完整PNG原稿，独立于应用源码保存。
- `../artwork/image-manifest.json`：原稿与应用WebP的SHA256、尺寸、字节数、编码参数。
- `web/course-assets/tier-主题ID-层级.webp`：随Windows与APK离线分发的174张主图。
- `../test-reports/visual-audit-v020.json`：按最终原稿SHA核对的人工目视审校；历史错误图的拒绝记录仍保留在各分组报告中。
- `../test-reports/diagram-coverage-v2.json` 与最终真实浏览器图片报告：检查174单元对应、文件解码、图片唯一性、替代文本及手机放大。

使用 `node tools/prepare_course_images.cjs --archive` 将已审PNG原稿复制到交付的artwork目录，并使用sharp 0.35.5编码为WebP，质量88、effort6，保留原稿尺寸（各图实际尺寸见资源清单）。归档前核对原稿SHA；只移走已验证的tier PNG副本，避免把同一幅大图以PNG和WebP重复装入应用。应用运行不需要sharp或任何AI服务。

## 审校方式

对照冻结后的每档课程及实际执行数据逐图查看原稿，核查数量、边界、引用方向、输入/输出、异常和事务语义。发现错误时重新生成或通过image_gen修改已查看的原稿，不能仅改图注掩盖图中错误。终稿批准记录绑定文件SHA，历史批准不能覆盖后续变更。最后对174张交付WebP进行文件与实际渲染检查。

开发时使用生成工具；产品不包含在线图片地址、模型调用、API密钥或联网生图功能。
