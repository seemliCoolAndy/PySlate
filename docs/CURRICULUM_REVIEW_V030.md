# PySlate 0.3.0 课程难度审阅

> 源码快照说明：安装包、测试报告、截图、PNG 原稿、交付校验清单及完整历史归档属于原始交付资料，未随本仓库提供。相关路径仅用于标识历史文件；本文保留的测试结果是原交付记录，不表示本次发布重新执行。当前可编辑源码位于仓库根目录。

本轮保留58个主题、174个三级单元及174张独立教学图。全量检查分层任务与结构后，重点增强33个单元：10个中级、23个高级，其中19个单元的示例或参考程序实质修改。58个初级单元保持入门负担；已有事务、图算法、TF-IDF、AST和多文件项目继续承担综合训练。

## 难度依据

- 初级：先掌握一个概念，完成可观察的小步骤。
- 中级：把概念迁移到变体，解释边界、输出协议及状态变化。
- 高级：定义可复用接口，用不变量、反例、独立参照或失败路径验证。
- 不以字数、代码行数或生僻语法作难度指标。新增前置知识列入单元prerequisites，早期高级路线适合后续回访。

## 修复的课程实现问题

基于上一版本原程序复现，以下五个断言旧版均失败、新版均通过。它们属于课程参考程序问题，应用运行时问题由平台报告另行记录。

| 问题 | 修复 |
|---|---|
| 嵌套可变内容污染历史快照 | deepcopy后保存，历史与来源隔离 |
| 新快照相同而容量缩小时不淘汰 | 去重后仍执行容量收缩 |
| 负矩阵尺寸静默变成空矩阵 | 非负整数契约明确拒绝负值、bool、浮点 |
| v2存档done=0被当合法 | 校验真正bool与任务字段 |
| v2存档重复ID被接受 | 校验正整数唯一ID |
