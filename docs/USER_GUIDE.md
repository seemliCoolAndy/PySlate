# PySlate 使用指南

> 源码快照说明：安装包、测试报告、截图、PNG 原稿、交付校验清单及完整历史归档属于原始交付资料，未随本仓库提供。相关路径仅用于标识历史文件；本文保留的测试结果是原交付记录，不表示本次发布重新执行。当前可编辑源码位于仓库根目录。

PySlate是一款免费的离线Python学习与编程软件。你可以阅读58个主题、174个学习单元的中文教材、运行真实Python代码，也可以像整理笔记一样管理自己的项目。无需登录、会员或在线AI服务。

## 安装与第一次打开

### Windows

适用目标为Windows10 22H2或Windows11 x64，需要.NET Framework4.8。运行交付目录中的`windows/PySlate-0.3.0-windows-x64-setup.exe`，阅读Microsoft WebView2许可，选择安装位置并安装。默认装到当前用户目录，内置CPython3.13.16，不必自己配置Python。

安装包包含完整WebView2离线组件；已安装合适版本时会复用。没有该组件时的全新系统安装分支尚未实测，组织策略也可能阻止安装。不要把这一限制理解为需要下载课程或Python。WebView2自身可能更新或发送诊断，条款见交付的licenses目录。

也可以完整解压便携ZIP，打开`PySlate.exe`。请保留旁边的`python/`、`runtime/`、`web/`、`course/`和DLL，不能只拷贝EXE，也不要从ZIP预览窗口运行。若缺少WebView2，可阅读许可后运行`redist/`中的离线安装器。便携版仍把学习数据放到本机用户数据目录，不随EXE一起携带。

Windows程序当前未做商业代码签名，系统可能提示未知发布者。校验值见Windows SHA256SUMS.txt（历史交付路径：`../windows/SHA256SUMS.txt`）；只运行来源可信且核对无误的文件。详细说明见[Windows指南](WINDOWS_GUIDE.md)。

### Android

把`android/PySlate-0.3.0-android.apk`传到设备，按系统的安装流程打开。系统可能要求你为本次使用的文件管理器允许“安装未知应用”；由你按设备提示选择，软件不会绕过该设置。校验值见Android SHA256SUMS.txt（历史交付路径：`../android/SHA256SUMS.txt`）。

最低要求Android8.0/API26，APK包含arm64-v8a和x86_64。当前实际验证为Android35 x86_64模拟器，实体手机、实体平板和ARM64执行尚未验证。APK采用开发签名；如果设备上已有同包名但签名不同的版本，不能保证直接覆盖安装。卸载会删除私有项目，先导出备份再处理安装冲突。

第一次打开无需创建账户。课程、插图与Python已经在安装包中，核心功能可断网使用。

## 0.3版有哪些变化

课程目录支持搜索主题和知识点，继续学习会回到上次选择的层级。58个主题依然各有初、中、高三级，共174个单元；每单元保留独立生成的概念图。33个中高级单元增加了推理、输入约束、边界案例或综合任务。初级仍适合第一次学习Python的人。

多文件课程现在直接展示和编辑main.py，正文和参考答案中可以展开“配套文件”阅读其他模块。载入示例或答案时，会同步选择其对应模块；之后修改入口、切课或重启，仍记住所选来源。示例与答案的练习目录分别保存，避免模块相互干扰。附带模块每次运行按所选教材版本准备；需要自由修改多个文件时，请在“我的项目”中建立标准项目。

## 开始第一课

1. 打开“Python学习”，可搜索主题或知识点，从“让Python说第一句话”开始，或按自己的前置知识选择章节。
2. 在课程顶部选择初级、中级或高级。先读目标、概念图与正文，预测示例输出；高级若列出“建议先学”，可点入对应初级课程补齐前置知识。
3. 在代码编辑器中查看示例，点击“运行”。第一次执行需阅读并确认本地代码信任提示。
4. 修改引号内的文字，再运行，观察真实结果。
5. 独立完成练习，再核对输入输出与参考答案。确认掌握时标记本层完成；三个层级分别计数，运行成功不会自动判定你已学会。

Windows和平板横屏可同时阅读课程与编辑代码，拖动中间分隔线调整宽度；分隔线取得键盘焦点后也可用左右键调整。手机使用“读课程”和“写代码/运行”切换，避免把两个狭窄面板挤在一起。手机代码区下方提供冒号、括号、引号和缩进等常用符号。

每个主题的初级、中级和高级草稿、完成标记、练习文件分别自动保存。升级前的草稿与完成标记继续对应初级；资料库项目不随课程难度变化。切换课程或层级后可以继续练习。“载入示例”与“查看答案”用于替换当前编辑内容，界面会在必要时确认；重要的个人版本可先复制到“我的项目”。进度、草稿和项目留在本机，不自动同步到其他设备。

课程共50个知识主题与8个项目，每个主题有初、中、高三级，共174单元。初级建立基本概念，中级组合应用并处理边界，高级包含调试、数据契约、状态推理和系统设计约束。先理解输入、变量、判断和循环，再学容器、函数、文件、模块与测试，最后逐步完成待办、数据分析、记账和多文件项目。预计时长是建议，不需要追赶进度数字。课程路线见[课程说明](COURSE.md)。

每个层级都有独立生成的本地概念图，用对象关系、执行路径和状态变化辅助理解。轻点图片可以放大；手机上可左右滑动查看完整图解，按“返回课程”或系统返回键关闭。

## 输入、输出与报错

程序执行到`input()`时会等待。看到“等待输入”后，在控制台下方亮起的输入框键入一行并按“发送”或回车。中文输入法选字确认不会提前发送；手机软键盘弹出后，控制台会缩小到可见区域。等待时切换项目文件仍保留输出和未发送的文字。每一次input通常需要一行；数字参与运算前仍要用int或float转换，例如`int(input('年龄：'))`。输入提示和你键入的文字可能显示在同一行，这是终端式交互的正常现象。

控制台结果来自真实CPython。出现红色traceback时，先看最后一行的异常类型与消息，再看对应文件和行号。SyntaxError多与括号、冒号和缩进有关，NameError常是名字拼写或尚未赋值，ValueError常是输入格式不符合要求。先用小数据复现，再一次修改一个原因。

点击方形“停止”按钮可结束正在运行的程序。每次运行最多累计执行30秒、输出最多256KiB；无限循环和大量输出会被终止。程序真正等候输入时暂停执行计时，每次输入最多等5分钟；空行也是合法的一行输入。停止不会撤销程序已经写入文件的内容。

Windows另有限制512MiB进程组提交内存、最多16个进程、256次输入请求及8192条事件；Android使用独立运行服务及有界输入/事件队列。界面仍可以显示运行完成、停止或超限原因。若保存失败，先处理提示，不要立刻关闭窗口。

## 创建自己的项目

1. 打开“我的项目”，点击“新建项目”，输入名称并选择封面颜色。
2. 打开项目，在`main.py`中编写代码。点击“运行”，或在文件较多时先用运行入口下拉框选择要启动的`.py`文件。
3. 点击“项目文件”旁的加号添加文件。可直接输入`utils.py`、`data/notes.txt`或`assets/config.json`，中间目录会自动建立。
4. 在`main.py`中使用`import utils`复用同目录模块，通过`open('data/notes.txt', encoding='utf-8')`读取项目资源。
5. 用项目菜单重命名、复制或删除，用分类标签与拖动整理项目，用搜索框查找名称。

项目是真实目录，代码是真实`.py`文件。名称与内部目录ID分开保存，不需要自己管理随机ID。多文件运行把项目目录设为工作目录；项目资源使用相对路径更容易在两端交换。重命名模块后需要同时修改import，重命名资源后也需要更新读取路径。

编辑器只处理不超过1MiB的UTF-8文本。图片等二进制资源可随ZIP保留，不能当作文字直接编辑。文本示例、Python标准库与普通文件是两端共同的基础；不要假定任意pip包、桌面GUI、系统命令或原生扩展都能在Android运行。

## 保存与快捷键

修改后会显示“正在保存”，完成后显示“已自动保存”。保存失败时会提示重试。切换文件或导出前，界面会提交待保存内容；Windows关闭窗口也会尝试等待最后编辑保存。仍建议在重要修改后确认保存状态，并定期导出项目。

| 操作 | Windows与实体键盘 |
|---|---|
| 立即保存 | Ctrl+S |
| 运行代码 | Ctrl+Enter |
| 缩进 | Tab |
| 搜索代码 | Ctrl+F |

“偏好设置”可切换浅色/深色主题，查看本地数据路径、运行版本和执行边界，也可以让下次运行重新显示信任提示。

## 在Windows与Android之间交换

在项目页点击“导出ZIP”，或从项目菜单导出。Android会打开系统文件选择器，让你指定保存位置；Windows使用下载/保存方式生成ZIP。把ZIP通过USB、局域网文件传输或你自己的存储方式送到另一台设备，再在“我的项目”选择“导入ZIP”。这是手动交换，不是云同步。

ZIP保留普通目录、`.py`和资源文件，不需要PySlate私有文件格式。导入通常创建一个新项目；同名项目可以并存，不把名字相同视为要覆盖原项目。交换后运行入口与相对资源路径仍需要正确。

为同时符合两端限制，建议ZIP不超过20MiB、展开后不超过50MiB、条目不超过1000、单个资源不超过10MiB。不要放入`..`、绝对路径、链接、加密条目、Windows设备名、大小写冲突路径或异常高压缩比内容。项目文件名统一使用正斜杠表达层级，不使用反斜杠。

## 备份、删除与卸载

**Windows：**学习进度、草稿和项目位于`%LOCALAPPDATA%/PySlate/Data`，与安装目录分开。退出应用后备份整个Data目录可保留完整学习资料；单个项目用ZIP备份。项目软删除与最近文件版本分别保存在trash和backups，目前没有图形恢复页；需要时先复制数据目录，再按[Windows指南](WINDOWS_GUIDE.md)手动取回。卸载应用会保留独立Data目录。

**Android：**数据位于应用私有目录。升级通常保留，卸载或“清除数据”会删除。普通用户不应依赖直接读取私有目录来备份，卸载、换机或清理前请先逐个导出重要项目。目前没有整份学习进度的跨设备导入功能；ZIP主要交换项目代码和资源。

课程中的待办和记账项目也会写自己的JSON或CSV，重新运行会读取旧数据。它们的演示期望输出以空项目首次运行计算；看到已有记录不代表保存异常。需要重新开始时先复制项目，再处理明确属于练习的数据文件。

## 只运行可信代码

Windows Python使用当前账户权限，可访问项目之外的文件、网络和系统程序，**不是安全沙箱**。Android运行服务与主界面共享应用UID，可访问本应用数据，也不是抵御恶意代码的文件安全沙箱。时间、内存、输出和进程限制不能替代文件权限隔离。

只运行自己编写、理解或可信来源的代码。导入别人的ZIP之前检查源代码。Windows中不可信程序应交给独立账户、虚拟机等系统隔离环境处理。PySlate不会通过模块黑名单承诺绝对安全。

## 常见情况

| 情况 | 处理方法 |
|---|---|
| Windows打不开界面 | 完整解压，确认x64/.NET4.8与WebView2存在；企业策略阻止组件时按组织规则处理 |
| Android安装冲突 | 先导出旧项目，检查系统版本、ABI和现有同包名应用的签名，不要直接卸载丢失数据 |
| 程序停住没有结果 | 看是否等待input；输入足够的行，或停止后用更小数据重试 |
| ModuleNotFoundError | 检查文件路径、模块名和import写法，避免自己的文件叫json.py、random.py等标准库名称 |
| 文件找不到 | 使用项目内相对路径，确认资源已添加；中文路径统一UTF-8文本编码 |
| ZIP导入失败 | 查看具体提示，减少体积，移除危险或不兼容条目；先保留原ZIP副本 |
| 保存失败或索引恢复提示 | 暂停删除和卸载，保留数据目录及原文件，备份后再按平台说明排查 |

完整验证范围、尚未执行的设备与安装分支见[交付报告](RELEASE_REPORT.md)。构建和维护方法见[源码README](../README.md)。
