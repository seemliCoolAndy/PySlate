# PySlate 界面与资源设计

> 源码快照说明：安装包、测试报告、截图、PNG 原稿、交付校验清单及完整历史归档属于原始交付资料，未随本仓库提供。相关路径仅用于标识历史文件；本文保留的测试结果是原交付记录，不表示本次发布重新执行。当前可编辑源码位于仓库根目录。

产品保留两个主模式：Python 学习、我的项目。设置仅包含主题、保存位置说明和运行边界，不引入登录、会员、云同步或 AI 入口。

桌面和横屏平板采用课程/编辑器双栏，拖动中线或用左右方向键调整 30%–70% 宽度。窄屏改为读课与代码/控制台切换；代码面板保留符号快捷栏，项目通过文件列表选择标准目录下的文本文件。输入框与报错同处控制台，不要求切换到另外的系统终端。

视觉采用灰白底、墨绿主色和少量暖黄，14–18像素圆角、清楚的文字层次、适量留白。资料库用有书脊的项目封面，封面颜色来自有限配色；浅色封面使用深色文字。学习目录采用可展开的章节列表，而非密集课程卡片。深色主题为同一套颜色变量，保持结构和交互一致。动画只用于轻微状态过渡，遵守 reduced-motion 设置。

使用系统中文字体与系统等宽字体，避免打包来源不清的字体或依赖联网字体服务。编辑器采用 CodeMirror 6 的解析、高亮、选区、搜索、撤销与键盘行为；Markdown 采用 Marked 并通过 DOMPurify 清理。所有 JavaScript/CSS 都本地打包，没有 CDN。图示、课程与 UI 逻辑分别维护。

实际验收：test-reports 下包含 Windows 原生 WebView2、Android 系统 WebView 与独立 Edge UI 自动化渲染。截图中的项目是测试创建的真实文件，不作为首次启动的预置用户项目。检查课程目录、浅深色资料库、双栏、代码/报错、390px手机及1024px平板布局；测试报告记录页面横向溢出与坏图检查。

原生 Windows 额外处理高 DPI 窗口尺寸与关闭前异步保存。Android 系统 Back 优先返回上一级界面，再在顶层请求退出。最后一轮修复对快速切页进行顺序提交、丢弃旧运行事件回包，并避免旧保存失败回滚较新内容。

0.2版为每个主题提供初级、中级、高级选择。草稿、练习与进度按层级保存，目录用三点显示该主题各档完成状态。图片以数据状态与执行关系辅助理解，轻点可放大。控制台只在Python实际请求输入时启用；等待时暂停计算时限，Android随真实软键盘调整WebView高度，中文候选确认不会误提交。


## 0.3阅读与操作调整

浅色基底#f5f5ef、面板#fffefa、墨绿强调色#215d49；深色基底#17231e、面板#1e2c25，主题共享布局。新增design.css集中维护此版视觉层，保留旧布局规则。使用更清楚的正文与标题比例、章节进度线、温和的练习底色；知识图片保持完整比例，不以裁剪制造装饰效果。首页用真实Python输入/输出展示学习方式，主题/层级/进度三项信息均来自课程或存档。

课程搜索同时匹配主题、章节及每层目标；未找到时提供清空搜索入口。搜索仅过滤目录，不修改学习进度。多文件课程可展开查看配套模块。手机的项目文件视图随宽屏自动恢复编辑器；320/390像素与平板、桌面布局均有自动化检查。颜色对比测试覆盖主导航、行动按钮、章节标题与说明文字，不代表完整无障碍认证。原生Android的窗口与系统栏随深浅主题同步。

本次UI回归入口：tools/test_review_v3.cjs、test_design_v3.cjs、test_companion_files_v3.cjs，以及原有test_learning_v2.cjs、test_ui.cjs。截图必须等主题过渡结束后检查，避免把中途混色当作最终外观。
