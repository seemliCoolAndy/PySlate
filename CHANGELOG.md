# Changelog

## 0.3.0 — 2026-10-23

This entry summarizes the release notes supplied with the 0.3.0 source snapshot. See `docs/RELEASE_REPORT.md` for reported validation results and limitations.

- Improved consistency when project saves, metadata validation, or index writes fail.
- Prevented case-insensitive filename collisions from overwriting existing files.
- Improved stop/input handling and editor state when switching layouts.
- Improved Windows installer rollback and protection against directory links.
- Improved Android project import/copy behavior, theme synchronization, and file handling.
- Reviewed and strengthened 33 intermediate/advanced learning units.
- Preserved 58 topics with three levels each and 174 bundled teaching illustrations.
